How TeacherFlowAI Reads These Scores

Use this guide so teachers know what each label means before acting on the dashboard.

Student Topic Labels

  • On Track: 70% or higher on that topic.
  • Below Target: below 70% on that topic.

Color Ranges

  • Green: 75% and above.
  • Yellow: 60% to 74%.
  • Red: below 60%.

Class Status Pills

  • Healthy: above 75% class average.
  • Watch: 60% to 75% class average.
  • Urgent: below 60% class average.

Weak Topic Alerts

  • An alert appears when more than 40% of students are below 70% on the same topic.
